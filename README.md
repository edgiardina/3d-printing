# 3D Printing

Designs for the Bambu Lab A1. One folder per project:

- `*.scad` - OpenSCAD source (the real design; tweak parameters at the top)
- `*.stl` - exported mesh, ready to slice
- `*.3mf` - Bambu Studio project with print settings (when saved)
- `preview.png` - render

## Projects

- [jukebox-bill-validator-dummy](jukebox-bill-validator-dummy/) - fake MEI-style bill validator plug for the NSM Emerald Ice jukebox (opening 3.25" x 1.5"). Print face down, black PLA, textured PEI, no supports.
